# Virtual CV — Yaseen Dawood

A single-page portfolio site built as a dynamic virtual CV. Live at:

**https://ydawood03.github.io/Virtual-CV/**

## About

This site showcases my background as a full-stack and applications developer — final-year BSc IT student at North-West University. It covers my work experience, technical skills, projects, education, and contact details in one place, built from scratch as a single self-contained HTML file.

## Sections

- **Home** — quick intro and current status
- **About** — background and focus areas
- **Experience** — work history, including Teaching Assistant role at NWU
- **Skills** — languages, frameworks, databases/infrastructure, and data analysis tools
- **Projects** — four deployed/production-facing builds:
  - [ForexTutorBot](https://github.com/YDawood03/ForexTutorBot) — AI-powered Forex study assistant (Flask, scikit-learn) deployed on Azure
  - [TayTech](https://github.com/YDawood03/TayTech) — C# desktop invoicing & client management system
  - [Sohail Manga Attorneys](https://github.com/YDawood03/Sohail-Manga-Attorneys-) — live corporate website for a law firm
  - [Blue River Zoo Management System](https://github.com/tsholofelospicegirl17-hub/BlueRiverZoo) — team-built C#/ASP.NET zoo operations app
- **Education** — BSc Information Technology, North-West University
- **Contact** — email, phone, GitHub, LinkedIn

## Tech

- HTML, CSS, and vanilla JavaScript — no build step, no framework
- [Vanta.js](https://www.vantajs.com/) (fog effect) + [Three.js](https://threejs.org/) for the animated background
- [Unicons](https://iconscout.com/unicons) for icons
- Google Fonts: Space Grotesk, Inter, JetBrains Mono

## Running locally

No build tools required — just open the file in a browser:

```bash
git clone https://github.com/YDawood03/Virtual-CV.git
cd Virtual-CV
open index.html
```

## Deployment

Hosted on **GitHub Pages**, deployed from the `main` branch root. Any push to `main` redeploys automatically.
